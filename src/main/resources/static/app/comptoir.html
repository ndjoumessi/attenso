Vos données

Cette clinique est responsable de ce traitement. Votre numéro de mobile sert uniquement à vous prévenir que votre tour approche, aujourd'hui, dans cette clinique. Il est effacé le lendemain ; votre numéro de ticket est conservé sans votre numéro, pour le décompte des passages.

Aucun compte n'est créé, aucune donnée de santé n'est collectée, et rien n'est utilisé à des fins commerciales. Pour y accéder, les corriger ou les faire effacer avant le lendemain, adressez-vous à l'accueil.
