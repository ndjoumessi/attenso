Politique de confidentialité

Attenso collecte le minimum nécessaire pour prévenir quelqu'un que son tour approche : un numéro de mobile et un numéro de ticket. Cette page dit exactement ce qui est conservé, combien de temps, et par qui.

Deux rôles à ne pas confondre

Pour les personnes qui se présentent dans un établissement, l'établissement est responsable de traitement et — agit comme sous-traitant : l'éditeur ne traite ces données que sur instruction de l'établissement, pour le seul fonctionnement de la file.

Pour les données de l'établissement lui-même — compte, abonnement, facturation — l'éditeur est responsable de traitement.

Ce qui est collecté, et pourquoi

Numéro de mobile
Facultatif. Sert uniquement à envoyer les messages d'avancement du jour. Sans lui, la personne reste dans la file et est appelée à la voix.
Numéro de ticket et horodatages
Position dans la file, heures d'arrivée, d'appel et de départ. Servent à faire fonctionner la file et à compter les départs sans consultation.
Compte de l'établissement
Adresse de connexion, mot de passe chiffré, formule souscrite.

Aucune adresse IP n'est conservée. Elle est utilisée en mémoire pour limiter les abus, puis oubliée ; un test automatisé vérifie qu'elle n'est jamais écrite.

Aucune donnée de santé humaine n'est collectée. Si l'établissement active le carnet de santé animal, le nom de l'animal, son espèce, ses vaccinations et le mobile de son propriétaire sont conservés tant que le carnet est actif — la finalité, un rappel de vaccin des mois plus tard, impose une durée différente de celle de la file. Le propriétaire peut demander la révocation du carnet à tout moment.

Combien de temps

Numéro de mobile d'un ticket
Effacé le lendemain, par une tâche quotidienne. La ligne du ticket demeure, sans le numéro : c'est elle qui porte les statistiques de fréquentation.
Statistiques de la file
Conservées tant que l'établissement est client, puis effacées.
Données de facturation
Dix ans, durée légale de conservation des pièces comptables.

Qui d'autre y a accès

Opérateur SMS
Reçoit le numéro et le texte du message, pour l'acheminer. Prestataire français, données traitées en France.
Prestataire de paiement
Reçoit les données de l'abonnement de l'établissement, jamais celles de ses clients. Les coordonnées bancaires sont saisies chez lui et ne transitent jamais par Attenso.
Hébergeur
Héberge les serveurs et la base, dans l'Union européenne. Voir les mentions légales.

Les données ne sont ni vendues, ni cédées, ni utilisées à des fins publicitaires. Aucun traqueur publicitaire, aucun cookie de mesure d'audience, aucune police de caractères chargée depuis un tiers : les pages d'Attenso ne font aucune requête vers un autre domaine.

Vos droits

Vous pouvez demander l'accès, la rectification, l'effacement ou la limitation de vos données, et vous opposer à leur traitement. Adressez-vous d'abord à l'établissement qui vous a reçu ; il peut nous solliciter si une intervention technique est nécessaire. Pour les données de compte d'un établissement, écrivez à —.

Vous pouvez également introduire une réclamation auprès de la CNIL.

Sécurité

Les échanges sont chiffrés. Les données de chaque établissement sont cloisonnées par une politique appliquée dans la base de données elle-même, et non seulement dans le code : une erreur de programmation ne peut pas faire apparaître la file d'un établissement chez un autre. Les mots de passe sont stockés sous forme d'empreinte, jamais en clair.
